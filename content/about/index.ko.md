## 안녕하세요, 김준석입니다

소프트웨어와 데이터 사이언스를 전공했으며, 백엔드와 애플리케이션 개발에 관심을 가지고 있습니다.

프론트엔드, 백엔드, 모바일 애플리케이션, 데이터 분석, 머신러닝 및 임베디드 소프트웨어 등 다양한 분야를 학습하고 프로젝트를 진행했습니다.

현재는 일본에서 개발자로 근무하며 실무 경험과 기술을 쌓고 있습니다.

## 기술

- Java, Spring
- JavaScript, React Native
- Python, pandas, scikit-learn
- MariaDB, MySQL
- Docker
- C, 임베디드 소프트웨어

## 관심 분야

- 백엔드 개발
- 웹 서비스 개발
- 모바일 애플리케이션
- 시스템 설계
- 데이터 분석
